# Installing Talky as an App

Talky can be installed on your device like a regular app! This guide shows you how to install it on different devices.

## 📱 Android Devices

### Google Chrome

1. **Open Talky in Chrome**
   - Visit https://talky.pages.dev (or your custom domain)

2. **Look for the install prompt**
   - You'll see a banner at the bottom saying "Install Talky App"
   - Or tap the **︙** menu icon (three dots) in the top-right corner

3. **Install the app**
   - Tap **"Install"** or **"Add to Home screen"**
   - Confirm by tapping **"Install"** again

4. **Open the installed app**
   - Find the Talky icon on your home screen
   - Tap to open - it runs like a native app!

### Samsung Internet

1. Visit the Talky website
2. Tap the **Menu** icon
3. Select **"Add page to"** → **"Home screen"**
4. Confirm installation

---

## 🍎 iPhone & iPad (iOS)

### Safari Browser

1. **Open Talky in Safari**
   - Visit https://talky.pages.dev in Safari browser
   - ⚠️ Must use Safari - won't work in Chrome on iOS

2. **Tap the Share button**
   - Look for the **⬆️ Share icon** at the bottom of the screen (iPhone)
   - Or at the top (iPad)

3. **Scroll down and tap "Add to Home Screen"**
   - You might need to scroll down in the share menu
   - Look for the icon with a **+** symbol

4. **Customize and add**
   - You can change the name if you want
   - Tap **"Add"** in the top-right corner

5. **Open the installed app**
   - Find the Talky icon on your home screen
   - Tap to open - runs in fullscreen mode!

### iOS Tips
- **No push notifications**: iOS Safari PWAs don't support push notifications yet
- **Refresh**: Pull down to refresh if you need to reload
- **Delete**: Long-press the icon and select "Remove App" to uninstall

---

## 💻 Desktop / Laptop

### Google Chrome (Windows, Mac, Linux)

1. **Open Talky in Chrome**
   - Visit https://talky.pages.dev

2. **Look for the install icon**
   - See the **⊕ Install** icon in the address bar (right side)
   - Or see a prompt at the bottom of the page

3. **Click Install**
   - Click the install icon or banner
   - Click **"Install"** in the confirmation dialog

4. **Launch the app**
   - Find Talky in your applications
   - Or launch from Chrome's app menu (Apps icon in bookmarks bar)

### Microsoft Edge (Windows, Mac)

1. Visit the Talky website in Edge
2. Click the **"App available. Install Talky"** button in the address bar
3. Or go to **Settings and more (...)** → **Apps** → **Install Talky**
4. Click **Install** to confirm

### macOS App Icon
After installation on Mac, Talky appears in:
- Applications folder
- Dock (if you drag it there)
- Launchpad

## 🗑️ Uninstalling the App

### Android
1. Long-press the Talky icon
2. Drag to **"Uninstall"** or **"Remove"**
3. Or go to Settings → Apps → Talky → Uninstall

### iOS
1. Long-press the Talky icon
2. Tap **"Remove App"**
3. Select **"Delete App"**

### Desktop (Chrome/Edge)
1. Right-click the Talky icon in app list
2. Select **"Uninstall"**
3. Or go to browser Settings → Apps → Manage apps → Uninstall Talky

## ❓ Troubleshooting

### "I don't see the install option"

**On Android/Desktop:**
- Make sure you're using Chrome, Edge, or Samsung Internet
- Try refreshing the page
- Check if you already installed it (look for Talky icon)
- Ensure you're using HTTPS (not HTTP)

**On iOS:**
- You MUST use Safari browser (not Chrome or others)
- Update to iOS 11.3 or later
- Make sure you're not in Private Browsing mode

### "The app icon looks wrong"

- Uninstall and reinstall the app
- Clear browser cache and try again
- The icon should be blue with a video call symbol

### "Offline mode isn't working"

- Make sure you opened the app at least once while online
- Check if service worker is enabled (Settings in browser)
- Offline mode shows cached data only - you can't make calls offline

### "Not getting notifications"

- **iOS**: Push notifications aren't supported on iOS PWAs yet (Apple limitation)
- **Android/Desktop**: 
  - Allow notifications when prompted
  - Check browser notification permissions
  - Ensure Talky has notification permission in system settings

### "App won't update"

- Close and reopen the app
- On Android: Clear app cache in Settings
- On iOS: Uninstall and reinstall
- On Desktop: Check for updates in browser settings
